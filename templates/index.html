What can I upload?

RAG CodeLens accepts project ZIP archives. Supported source files are extracted for browsing and analysis.

Does it replace code review?

No. It is a context and exploration tool that helps developers understand a project before and during review.

Where do I start?

Create an account, upload a project archive, then use the dashboard and AI tools to explore it.
