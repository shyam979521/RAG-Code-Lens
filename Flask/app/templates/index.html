How It Works

The RAG pipeline behind RAG Code Lens.

1

Upload Codebase

Upload your project as a ZIP file. The system parses all source files and extracts meaningful code chunks.

2

Embedding & Indexing

Code chunks are converted into vector embeddings and stored in a vector database for fast semantic retrieval.

3

Query Processing

Your natural language question is embedded and matched against the most relevant code chunks using similarity search.

4

LLM-Powered Response

Retrieved code context is fed to a large language model which generates a clear, detailed answer with references.
